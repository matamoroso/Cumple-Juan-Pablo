# Cumple-Juan-Pablo

Invitación digital interactiva para el cumpleaños de 10 años de Juan Pablo.

## Publicar en GitHub Pages

1. Abrí el repositorio `Cumple-Juan-Pablo`.
2. Extraé este ZIP y subí **el contenido**, no la carpeta contenedora.
3. Confirmá que se vean `index.html`, `styles.css`, `app.js`, `assets` y `.github` en la raíz.
4. Hacé `Commit changes` sobre la rama `main`.
5. Entrá en `Settings > Pages`.
6. En `Build and deployment > Source`, elegí `GitHub Actions`.
7. Entrá en `Actions` y esperá que `Deploy GitHub Pages` quede en verde.
8. La URL será `https://TU-USUARIO.github.io/Cumple-Juan-Pablo/`.
